# Wax It Lagos — Concept Website

A cinematic, immersive concept site for **Wax It Lagos**, the waxing spa at 7A Taiye Olowu Street, Lekki Phase 1.

Concept: **SILK** — smooth skin as one flowing sheet of 3D silk. The silk fills the hero, ripples where you touch it, smooths out as you scroll through the visit, and re-tints itself for every treatment in the Silk Lab.
